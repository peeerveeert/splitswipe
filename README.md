# SplitSwipe v1.0

Мобильное PWA для разделения покупок по чекам между тремя постоянными участниками.

## Использование

1. Введите магазин, дату, сумму чека и плательщика.
2. Загрузите фото и нажмите «Распознать фото» либо добавьте товары вручную.
3. Проверьте строки и итоговую сумму. OCR экспериментальный: весовые товары и количество могут распознаваться неверно.
4. Распределите карточки: влево — только я, вниз — первые двое, вправо — все трое. «Другие участники» позволяет выбрать любую комбинацию.
5. Скопируйте расчёт, сохраните чек.

Данные хранятся только в localStorage браузера. Синхронизации между устройствами нет. Используйте экспорт JSON для резервного копирования.

## Публикация

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Откройте сайт в Safari → Поделиться → На экран «Домой».

OCR загружает Tesseract.js через CDN и требует интернет. Не загружайте реальные чеки в публичный репозиторий.
